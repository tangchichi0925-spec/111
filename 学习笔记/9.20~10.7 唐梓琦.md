## 9.数组


### 9.1定义与使用
#### 知识点

数组适合保存一组同类型数据
数组可以在定义时直接初始化,也可以只给一部分元素赋值
```c
int arr[5] = {10, 20};
```

此时后面的元素会被初始化为 `0`。

定义格式：

```c
数据类型 数组名[数组长度];
```
数组元素通过下标访问：

```c
arr[0]
arr[1]
arr[2]
arr[3]
arr[4]
```
长度为 5 的数组，合法下标是 `0` 到 `4`。
#### 语法
```c
int arr[5] = {10, 20, 30, 40, 50};//定义数组并初始化
printf("%d\n", arr[0]);//获取索引为0的元素
```
#### 易错点
- `int arr[5];` 中的 `5` 表示数组长度，不表示最大下标。
- 最大下标是 `长度 - 1`。
- `arr[5]` 对这个数组来说越界了。

### 9.4最值问题-十只小猪称体重
题目：有 10 只小猪，体重如下：

```text
300 350 200 400 250 380 280 500 320 260
```
找最重的猪
核心思路：

1. ==先假设第一个元素最大。==
2. 从第二个元素开始逐个比较。
3. 如果发现更大的值，就更新最大值。
#### 语法
```c
int max = arr[0];

for (int i = 1; i < 10; i++)
{
    if (arr[i] > max)
    {
        max = arr[i];
    }
}
```
#### 对应代码
```c
#include <stdio.h>

int main()
{
    int weights[10] = {300, 350, 200, 400, 250, 380, 280, 500, 320, 260};
    int max = weights[0];

    for (int i = 1; i < 10; i++)
    {
        if (weights[i] > max)
        {
            max = weights[i];
        }
    }

    printf("最重的小猪体重是：%d\n", max);

    return 0;
}
```

## 11.指针

### 11.1指针定义

#### 知识点

指针变量专门用来保存地址。普通变量保存的是数据，指针变量保存的是某个变量在内存中的位置。通过 `&变量名` 可以取得地址，通过 `*指针变量`  可以访问这个地址里的数据。

#### 语法

```c
int a = 10;
int *p = &a;
printf("%d\n", *p);

```
#### 易错点

- `p` 保存地址，`*p` 表示地址中存放的值。
- `p` 保存地址，`*p` 表示地址中存放的值。

### 11.2讲解

- 可以把变量理解为一块有名字的内存空间，地址就是这块空间的编号。指针变量保存这个编号，所以能通过编号找到原来的变量空间。

- 修改变量

```c

int age = 18;

int *p = &age;

*p = 19;

```
- ==不同类型的指针要指向对应类型的数据==
```c

int a = 10;

double b = 3.14;

int *p1 = &a;

double *p2 = &b;

```
### 11.3指针和参数

#### 知识点

普通参数是值传递，函数内修改形参不会影响实参。指针参数接收变量地址，函数内通过 `*p` 修改地址中的数据，可以影响外部变量。==操作其他函数的变量==！
#### 语法
```c

void swap(int *a, int *b);

```

#### 代码
```
#include <stdio.h>
void swap(int *a, int *b)
//调用后传到这里0x0011,0x0022

{
    int temp = *a;

    *a = *b;

    *b = temp;

}

int main()

{

    int x = 10;//假如是0x0011

    int y = 20;//假如是0x0022

    swap(&x, &y);

    printf("x = %d, y = %d\n", x, y);
    return 0;

}
```
### 11.4指针运算
#### 知识点
数组名在很多表达式中会转换为首元素地址。`int *p = arr;` 后，`p` 指向 `arr[0]`。`p + 1` 不是地址加 1 个字节，而是移动到下一个 `int` 元素。
#### 语法
```c

int arr[5] = {1, 2, 3, 4, 5};

int *p = &arr[0];//获取内存地址

printf("%d\n", *(p + 2));//通过内存地址获取数据

```
- ==指针＋1==：往前移动一个步长
步长跟数据类型有关，即和指针类型有关
### 11.5野指针空指针万能指针
#### 野指针
野指针指向未知或已经无效的空间，不能解引用。
#### 空指针
空指针一般表示“暂时不指向任何有效空间”。
#### 万能指针
`void *` 可以保存任意类型地址，但使用前需要转换成具体类型指针。
```c

int *p = NULL;

if (p != NULL) { printf("%d\n", *p); }

```

```c

#include <stdio.h>

int main()

{

    int num = 10;

    int *p = NULL;

    void *vp = &num;

    if (p == NULL)

    {

        printf("p is NULL, do not use *p\n");

    }
    p = &num;

    printf("*p = %d\n", *p);

    printf("void pointer value = %d\n", *(int *)vp);
    return 0;

}

```
- 没有初始化的指针不要使用。

- ==空指针可以判断，但不能解引用==。

- `void *` 不能直接 `*vp`，要先转换类型。

### 11.7指针数组
#### 知识点
指针数组本质上是数组，数组中的每个元素都是指针。例如 `const char *names[3]` 可以保存 3 个字符串的首地址。
```c

#include <stdio.h>
int main()

{

    const char *names[3] = {"Tom", "Jack", "Rose"};
    for (int i = 0; i < 3; i++)

    {

        printf("names[%d] = %s\n", i, names[i]);

    }
    return 0;

}

```

#### 易错点
- `const char *names[3]` 是指针数组，先看 `names[3]` 表示它是数组。

- 字符串字面量通常不要修改，所以用 `const char *` 更合适。

- 指针数组保存的是地址，不是把所有字符都放进同一块二维数组。

- 区分数组指针和指针数组：`int (*p)[3]` 是数组==指针==，适合指向二维数组中的一整行。`int *p[3]` 是指针==数组==，不是数组指针，含义完全不同。
  

### 11.8指针遍历二维数组

#### 知识点

二维数组可以看成“多行多列”的表格：

```c
int arr[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

它有 2 行、3 列。
遍历二维数组有三种常见写法。

##### 写法一：索引遍历

```c
for (int i = 0; i < 2; i++)
{
    for (int j = 0; j < 3; j++)
    {
        printf("%d ", arr[i][j]);
    }
    printf("\n");
}
```
##### 写法二：数组指针遍历
```c
int (*p)[3] = arr;
//二维数组名 `arr` 可以理解为指向第 0 行的地址。
```

含义：

- `p` 是一个指针。
- `p` 指向“一行 3 个 int”的数组。
- `p + 1` 会跳到下一整行。

访问元素：

```c
*(*(p + i) + j)
```

它和下面写法等价：

```c
p[i][j]
arr[i][j]
```
```c
#include <stdio.h>

int main()
{
    int arr[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };
    int (*p)[3] = arr;//获取二维指针
    for (int i = 0; i < 2; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            printf("%d ", *(*(p + i) + j));＋/-表示偏移量，想象成移动
        }
        printf("\n");
    }
```

###12.1定义 
#### 知识点
C语言内置类型一次只能描述**一个属性**：`int age;` 只能存年龄。但现实中一个"学生"同时有姓名（字符数组）、年龄（整型）、成绩（浮点）——**类型还不相同**。

结构体 = ==把多个不同类型的数据打包成一个新类型==。

struct Student {

struct Point {

    int y;

    printf("sizeof(struct Point)   = %d\n", (int)sizeof(struct Point));

    /* 类型只是图纸，可以定义任意多个变量 */
    struct Student stu1;
    struct Student stu2;
    struct Point   p1;

    printf("定义变量后：stu1、stu2、p1 各自占用内存\n");
    return 0;
